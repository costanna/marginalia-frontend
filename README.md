# Marginalia · Frontend

Web app for **Marginalia**, an AI-powered English corrector that annotates a learner's text like a
teacher's margin notes, estimates the CEFR level and builds personalised exercises.

> Status: **Phase 0 (project setup)**. The Angular project is created in Phase 3.

Backend: [marginalia-backend](https://github.com/costanna/marginalia-backend)

## Stack

Angular (standalone components, signals) · TypeScript strict · SCSS with CSS variables · Transloco
(ca / es / en) · Chart.js · self-hosted Inter and Fraunces fonts · deployed on Vercel

## Cross-cutting requirements

Dark mode (light / dark / system) · three UI languages · responsive from 320 px to 1920 px ·
footer with © and @costanna on every page · WCAG 2.1 AA.

## Roadmap

CI for this repo (lint, tests, production build) is added together with the Angular project in Phase 3.
